# Level-2-Assignment-1

This repository contains the solutions to Assignment 1 for Programming Hero Level-2 Web Development Course. 

It contains some problem solving exercises and two blogs. One of the blogs is a small discussion on the differences of `any` and `unknown` types in TypeScript and how one is more `type-safe`. Another blog is about the `Generics` tool in TypeScript and how it makes components in a codebase reusable while giving type safety.
